# NO SIGNAL — мобильный веб-прототип

NO SIGNAL — редакционный музыкальный журнал: один альбом дня, контекст, проверенные факты, заметки к каждому треку и личный архив.

## Что работает в версии 0.1
- Адаптивный интерфейс под iPhone и desktop.
- Главная страница «Альбом дня».
- Архив с поиском и фильтрами.
- Выпуск альбома с трек-листом, раскрывающимися заметками и источниками.
- Сохранение альбомов и реакции «Зацепило / Мимо / Позже».
- Локальное хранение сохранений и реакций в браузере.
- PWA manifest и service worker для установки/кэширования после HTTPS-размещения.
- Не требует сборщика или сторонних библиотек.

## Как посмотреть сейчас
Открой `index.html` в браузере. Для полноценной установки на iPhone и работы service worker сайт должен быть опубликован по HTTPS (или открыт на localhost).

## Как установить на iPhone после публикации
1. Открой URL сайта в Safari.
2. Нажми «Поделиться».
3. Выбери «На экран Домой» и подтверди.

## Публикация без компьютера (через iPhone)
Один из вариантов — создать репозиторий GitHub в Safari, загрузить файлы из этого архива и включить GitHub Pages в настройках репозитория. После публикации на HTTPS приложение можно добавить на экран «Домой». Сам прототип не создаёт хостинг и не выдаёт публичный URL автоматически.

## Важно
- Обложки в макете — авторские CSS-иллюстрации для редакционного интерфейса, а не копии обложек альбомов.
- Примерный архив предназначен для демонстрации UI. Некоторые редакционные описания треков — субъективные ориентиры для прослушивания.
- Реакции и сохранённое хранятся локально в том браузере, где ты открыл приложение; сейчас нет аккаунтов, облачной синхронизации и автоматической подгрузки новых альбомов.

## Автопубликация через GitHub Pages

В комплект добавлен workflow `.github/workflows/deploy.yml`: после загрузки файлов в ветку `main` он публикует сайт через GitHub Pages. В настройках репозитория открой **Settings → Pages** и выбери **Source: GitHub Actions**. После успешного запуска workflow GitHub покажет публичный адрес сайта в разделе Pages и в summary запуска.
